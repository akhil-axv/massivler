# Python sabaqları: Massivler hám ámeliyatlar

Bul repository Python boyınsha sabaq hám tapsırma faylların saqlaydı. Mısallar tiykarǵı sintaksis, shártli operatorlar, cikller, listler hám ápiwayı esaplawlarǵa tiyisli.

## Iske túsiriw

Python 3.10 yamasa jańaraq versiyasın ornatıń. Kerekli fayldı terminalda iske túsiriń:

```bash
python 31-sabaq.py
```

Fayl atın ózińiz isletpekshi bolǵan sabaq faylı menen almastırıń.

## Fayllar

- `*-sabaq.py`: sabaq mısalları hám shınıǵıwlar
- `qosimsha.py`: qosımsha praktikalıq mısallar
- `tapsirma.py`: tekst hám list operaciyaları
- `tapsirma.html` / `tapsirma.css`: HTML/CSS shınıǵıwı

## Úles qosıw

Jańa mısallardı bólek hám túsinikli at penen qosıń. Kodqa qısqa túsindirme jazıń hám iske túsiriwden aldın sintaksisin tekseriń.

## Qáwipsizlik

Bul oqıw repositorysi. Belgisiz kodtı iske túsirmesten aldın onı oqıp shıǵıń. Esaplaw ushın Python `eval()` funkciyasın paydalanbań.
